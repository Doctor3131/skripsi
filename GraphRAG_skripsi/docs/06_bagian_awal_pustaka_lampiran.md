# 7. Bagian awal, daftar pustaka, dan lampiran

## Abstrak / Abstract

- [ ] **Susun setelah hasil final**. Alur: masalah → tujuan → data/metode → metrik → temuan utama yang sudah diverifikasi → implikasi.
- [ ] **Periksa konsistensi dua bahasa**. Angka, klaim, nama model, dan istilah harus sama.
- [ ] **Handoff ke agent**. Berikan `rq_matrix.md`, desain final, tabel hasil, dan kesimpulan yang disetujui; jangan meminta agent menebak angka.

## Unsur formal dan referensi

- [ ] Cocokkan halaman judul, pengesahan, pernyataan, kata pengantar dengan pedoman kampus terbaru yang kamu miliki.
- [ ] Sinkronkan daftar isi dan penomoran bab/subbab hingga tingkat terbawah yang digunakan.
- [ ] Sinkronkan daftar gambar, tabel, source code, persamaan, dan lampiran.
- [ ] Pastikan semua kutipan memiliki referensi; semua entri daftar pustaka dirujuk dan sesuai aturan kampus.
- [ ] Periksa DOI/URL/judul/penulis/tahun langsung terhadap sumber asli, bukan hanya keluaran agent.
- [ ] Pastikan gambar/tabel menyebut sumber jika diadaptasi, dan memiliki penjelasan dalam teks.

## Lampiran dan reproducibility package

- [ ] Simpan instrumen/rubrik/anotasi dan dokumen izin yang boleh dilampirkan.
- [ ] Simpan definisi split dan ID anonim, skema fitur, konfigurasi, pseudocode, dan contoh perhitungan.
- [ ] Simpan tabel output rinci yang terlalu panjang untuk Bab IV.
- [ ] Simpan daftar versi/dependency, README cara menjalankan pipeline, serta manifest artefak.
- [ ] Hapus PII, kredensial, data rahasia, dan akses internal dari lampiran publik.
